# Task Tracker

Full-stack task management application.

## Project Structure

- `client/` — Frontend (React, TypeScript, Tailwind CSS)
- `server/` — Backend (Node.js, Express.js)
- `infrastructure/` — DevOps configuration (Docker, Nginx)

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Docker
- Nginx
- Linux
- Git
